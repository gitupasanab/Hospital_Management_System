# Hospital Management System
# Overview
This project is a Hospital Management System designed to efficiently manage hospital operations, including patient records, doctor assignments, appointments, and billing. The system uses SQL for the database and Streamlit for the frontend, providing a user-friendly interface for managing hospital workflows.
# Tech Stack
1. Frontend: Streamlit (Python)
2. Backend: MySQL
3. Database Management: SQL queries for CRUD operations
4. Development Environment: VS Code
# Features
# 1.Patient Management
1.1 Add, update, and delete patient records
1.2 Store patient details (name, age, medical history, etc.)
# 2. Doctor Management
2.1 Maintain doctor details (specialization, availability)
2.2 Assign doctors to patients
# 3. Appointment Scheduling
3.1 Book, update, and cancel appointments
3.2 Display appointment history
# 4. Manages Medical Record
4.1 Maintains comprehensive patient histories, including diagnoses, treatments, and medications.
# 5. Supports Staff Management
5.1 Handles staff schedules, roles, and performance tracking.
